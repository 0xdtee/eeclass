## 1. 系统架构

```
网页 / iPad App / Word 插件  ──WSS/HTTPS──►  Python 后端 (aiohttp, HTTPS :5901)
                                             ├─ sherpa-onnx SenseVoice   识别(CPU)
                                             ├─ 阿里云 DashScope         识别(可选:方言/多语言流式)
                                             ├─ silero VAD               断句
                                             ├─ 3D-Speaker eres2netv2    声纹
                                             ├─ PostgreSQL               账号/会话/课程元数据
                                             ├─ records/                 音频/转写/板书(文件)
                                             └─ DeepSeek API             文本+翻译(可选)
```

- **后端**:Python + aiohttp,承载识别、声纹、账号、AI。**识别/声纹全程 CPU**,无需 GPU。
- **前端**:React 19 + Vite + TS + Tailwind。`frontend/` 桌面网页;`mobile/` 移动端(同时构建网页 `/m` 与 iPad 原生 App)。
- **数据**:账号/会话/课程元数据在 PostgreSQL;音频、逐句转写、板书是 `records/` 下的文件。

## 2. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| Python | 3.11+ | 后端 |
| Node.js | 18+ | 前端/移动端构建 |
| PostgreSQL | 14+ | 账号与元数据库 |
| ffmpeg | 任意近版 | 音频处理 |
| 磁盘 | ~2 GB | 语音模型(首次安装自动下载) |
| DeepSeek API Key | 可选 | AI 摘要/纠错/翻译;**不填也能识别** |

支持 macOS / Windows / Linux。macOS、Windows 有一键脚本;Linux 参照手动步骤。

## 3. 快速安装

先克隆仓库:

```bash
git clone https://github.com/0xdtee/eeclass.git
cd eeclass
```

### macOS

```bash
bash setup-mac.sh      # 装 node/python/ffmpeg + 依赖,下载 ~2GB 语音模型
```

### Windows

```powershell
backend\scripts\install.ps1     # 依赖 + 模型
backend\scripts\start.ps1       # 启动后端
```

### Linux(手动)

```bash
# 1) 系统依赖
sudo apt install -y python3.11 python3.11-venv ffmpeg postgresql nodejs npm

# 2) 后端虚拟环境
cd backend
python3.11 -m venv .venv
./.venv/bin/pip install -r requirements.txt

# 3) 语音模型:参照 setup-mac.sh 里的下载地址,放到 backend/service/models/
#    (SenseVoice 识别、CT-Transformer 标点、eres2netv2 声纹、silero VAD)

# 4) 前端依赖
cd ../frontend && npm install
cd ../mobile   && npm install
```

> 语音模型来自 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 与 [3D-Speaker](https://github.com/modelscope/3D-Speaker) 的发布页,本仓库不再分发,安装脚本会自动拉取,各自遵循上游许可。

## 4. 配置

### 4.1 配置文件

```bash
cp backend/service/config.example.json backend/service/config.json
```

`config.json` 里**不要写密钥**(密钥走环境变量)。常用可调项:

| 位置 | 字段 | 含义 |
|---|---|---|
| `asr.backend` | `sensevoice` / `zipformer` / `funasr` / `aliyun_paraformer` / `aliyun_funasr` | 识别后端。默认 `sensevoice`(CPU 最快);逐字流式用 `zipformer`;方言用云端 `aliyun_funasr` |
| `asr.hotwords` | 空格分隔词表 | 专业术语热词,提升识别准确率 |
| `vad.threshold` | 0.35(默认) | 拾音灵敏度,可在控制台实时调 |
| `speaker.enabled` | `true` | 说话人分离开关 |
| `server.port` | `5901` | 后端 HTTPS 端口 |
| `server.host` | `0.0.0.0` / `127.0.0.1` | `0.0.0.0`=同 WiFi 手机可访问;仅本机改 `127.0.0.1` |
| `server.require_token` | `true` | 令牌门禁,公网必开 |
| `server.public` | `false` | 暴露到公网时设 `true`(页面也需令牌、错误锁 IP、访问记日志) |
| `invite_code` | 空 | 非空则注册需邀请码;空=开放注册 |

### 4.2 环境变量(密钥/连接串都放这里,不进文件、不进 git)

| 环境变量 | 必需? | 用途 |
|---|---|---|
| `EECLASS_DB_DSN` | **是** | PostgreSQL 连接串,如 `postgresql:///eeclass`(本机 peer 认证免密) |
| `DEEPSEEK_API_KEY` | 可选 | AI 摘要/纠错/翻译。不填则识别可用、AI 功能关闭 |
| `DASHSCOPE_API_KEY` | 可选 | 阿里云百炼云端识别(方言/多语言流式) |
| `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` `SMTP_FROM` `SMTP_FROM_NAME` | 可选 | 邮箱验证码注册。不配则无法邮箱注册(可改用邀请码/预建账号) |
| `ALIBABA_CLOUD_ACCESS_KEY_ID` `ALIBABA_CLOUD_ACCESS_KEY_SECRET` `OSS_BUCKET` `OSS_REGION` | 可选 | 阿里云 OSS 音频/文件转存备份 |

示例:

```bash
export EECLASS_DB_DSN=postgresql:///eeclass
export DEEPSEEK_API_KEY=sk-你的key           # 可选
export DASHSCOPE_API_KEY=sk-你的key          # 可选,云端识别
```

### 4.3 建数据库

```bash
sudo -u postgres createuser --superuser $USER   # 让当前用户能 peer 登录(本机)
createdb eeclass
```

后端首次启动会自动建表(`db.py` 内置 schema)。若你有旧的 JSON 数据要迁移,用 `backend/service/migrate_to_db.py`。

### 4.4 TLS 证书与令牌

- 后端走 HTTPS。首次启动会自建**自签证书**(浏览器会有安全警告,自托管点"继续"即可)。
- 开启 `require_token` 后,访问令牌写在 `backend/service/token.txt`(不存在会自动生成)。把令牌发给该加入的人,或用账号登录(登录本身即认证,无需再抄令牌)。

## 5. 运行

### 开发模式(两个终端,热重载)

```bash
# A —— 后端(识别服务,HTTPS :5901)
cd backend
DEEPSEEK_API_KEY=sk-你的key ./.venv/bin/python service/server.py

# B —— 前端(热重载 :3000)
cd frontend
npm run dev
```

浏览器打开 **http://localhost:3000/course**。前端在开发模式会自动连本机 `localhost:5901` 后端。

## 6. 构建与部署(局域网 / 手机 / iPad)

### 6.1 构建网页产物

```bash
cd frontend && BASE_PATH=/app/ npm run build     # 桌面版 → out/,由后端在 /app 提供
cd mobile   && BASE_PATH=/     npm run build      # 移动版 → out/,由后端在 /m 提供
```

> ⚠️ 桌面版**必须**带 `BASE_PATH=/app/`,否则线上资源路径写成根路径导致白屏(404)。

启动后端后:

- 桌面版:**https://<你的IP>:5901/app/course**
- 移动版:**https://<你的IP>:5901/m**

同一 WiFi 下手机/平板直接开上面的地址即可(自签证书,接受警告)。是否需要令牌由 `server.require_token` 决定。

### 6.2 iPad 原生 App(可选)

移动端源码可通过 [Capacitor](https://capacitorjs.com/) 打成 iPad 原生 App:

1. 改后端地址:`mobile/src/lib/api.ts` 里的 `BACKEND` 常量改成你自己的后端(网页 `/m` 用同源、不受影响,只有原生 App 需要改)。
2. 构建并拷进 Capacitor 壳工程:
   ```bash
   cd mobile && BASE_PATH=/ npm run build
   cp -r out <你的 Capacitor 工程>/www
   cd <你的 Capacitor 工程>
   npx cap sync ios
   ```
3. 用 Xcode(或 `xcodebuild` + `devicectl`)构建、签名、装机。需自备 Apple 开发者签名。

## 7. 使用

1. **注册 / 登录**:开放注册用邮箱验证码(需配 SMTP)或邀请码;数据按账号严格隔离,各人只看到自己的课。
2. **上课录音**:进"录音"页,点开始 → 实时字幕、老师/学生分离、标重点、拍板书(自动对齐时间轴)。停止后可自动跳转并生成摘要。
3. **课后复习**:
   - 看本节课**摘要 + 重点**;一键**替换识别听错的词**(改写全文并记住)。
   - 进课程看整门课**大总结 / 考点饼图 / 模拟卷 / 录音集合**;用**闪卡 / 测验**自测。
   - 转写全文页可**行内编辑**、**点句子定位音频回放**。
4. **搜索**:跨所有课时全文检索到某一句。
5. **课表 / 参考资料**:逐级下钻课表;查阅教材与大纲。
6. **多设备**:课上用 iPad 录、课后用手机/电脑网页复习,同一后端、同一份数据。

> 部分功能是上海大学专属(教务系统课表自动导入、官方大纲库),其它学校用不了,但不影响核心系统。

## 8. 排错 FAQ

- **线上白屏、资源 404**:桌面版没带 `BASE_PATH=/app/` 构建。重新用正确命令构建。
- **浏览器安全警告 / 打不开**:自签证书所致,点"继续/信任"即可;或换成正式证书。
- **识别不出字**:确认模型已下载到 `backend/service/models/`;可在控制台调高拾音灵敏度(降 `vad.threshold`)。
- **AI 摘要/翻译无效**:未设 `DEEPSEEK_API_KEY`。识别不受影响。
- **多人同时说话完全不识别**:重叠语音是单说话人识别模型的固有限制,非配置问题。
- **邮箱注册收不到码**:未配 `SMTP_*`;改用邀请码或预建账号。
- **手机连不上**:`server.host` 需为 `0.0.0.0`,且和电脑在同一局域网;检查防火墙放行 5901。

## 9. 安全须知

- AI 功能会把转写**文本**发给 DeepSeek;关闭 AI 功能则无任何外部调用。
- 密码用 pbkdf2 哈希;会话基于令牌;令牌门禁有暴力破解锁定。
- **按账号严格数据隔离**——每个账号只看到自己的课、课程、课表和声纹库。
- 机密(`config.json`、`token.txt`、`certs/`、`start-server.sh` 里的环境变量)、全部用户数据(`records/`)、模型权重都已被 `.gitignore` 排除,**绝不入库**。数据库连接串与 API Key 放环境变量,不要写进文件。
